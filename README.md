# CapHub Studio

Editor gratuito de animações 2D e vídeos com formas geométricas e Countryballs.

## CapHub Studio 0.1

- Editor visual adaptado para celular e computador.
- Formas geométricas, texto, Countryballs e importação de imagens.
- Animação por posição inicial/final, duração e rotação.
- Linha do tempo simples e pré-visualização.
- Salvamento local no navegador e exportação/importação de projeto JSON.
- Exportação de animação em WebM (quando suportada pelo navegador) e captura PNG.

## Como executar

Abra `index.html` em um navegador moderno ou publique o repositório com GitHub Pages / Cloudflare Pages. Não precisa de build nem dependências externas.

## Limitações desta versão

A exportação de vídeo é WebM, não MP4. Edição multipista avançada, áudio, transições e conversão para MP4 ficam para versões futuras.
